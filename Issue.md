***What will be in the contract page***
Visible to both client and freelancer:

Field	Details
Project title	Pulled from the job post
Client name	—
Freelancer name	—
Contract status badge	Active / Completed / Disputed
Total budget	₹
Contract type	Milestone-wise
Start date	—
Deadline	—
Milestone list (table)	Title | Description | Amount | Due Date | Status
Payment progress bar	e.g., "₹20,000 / ₹60,000 released"

***Client side ***
Client-side extra actions
Fund Milestone button (next to each pending milestone → triggers escrow funding)
Approve / Request Revision button (once freelancer submits a milestone)
Raise Dispute option
Terminate Contract button (with confirmation + warning about partial payment)
Download Invoice/Receipt per released milestone

***Freelancer side ***
Freelancer-side extra actions
Submit Milestone button (upload deliverable/link + notes, only enabled if milestone status = funded)
View Escrow Status per milestone (funded / pending / released) — so they know it's safe to start work
Raise Dispute option
Withdraw funds shortcut (to their wallet/bank, separate from contract page but a link out)
